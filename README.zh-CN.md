# SnakeMatch3

俯视角 · 局域网多人 · **贪吃蛇 × 三消** 对战。跑在本地即可全屋联机。

> 目标不是变长，而是**把自己身上的珠子全部消完**。先归零者夺得一座奖杯。

*[English](README.md)*

界面有中英两套文案，按浏览器语言自动选择（任何中文语言环境显示中文，其余显示英文），登录界面也可以手动切换。

## 启动

```bash
npm install
```

装好之后，**`run/` 里的三个脚本双击就能用**（不想用命令行的话）：

| 双击 | 作用 |
|---|---|
| `run/1-start-server.cmd` | 起服务器。本机只允许一个实例，端口被占会直接报错并说明怎么办 |
| `run/2-open-game.cmd` | 用默认浏览器打开游戏；服务器没起会提示先去起服务器 |
| `run/3-start-and-play.cmd` | 起服务器，等它真的能连上了再自动开浏览器 |

命令行等价物：

```bash
npm start                    # 只起服务器
node scripts/run.js client   # 只开浏览器
node scripts/run.js both     # 起服务器并开浏览器
npm run start:plain          # 直接用 node 起，不做进程改名
npm test                     # 回归测试
npm run stress               # 服务器压测
```

启动后终端会打印本机与局域网地址，同一网络下的任何设备打开即可加入：

```
local: http://localhost:3000
LAN:   http://192.168.x.x:3000
```

无需注册，填个昵称就进（留空则自动分配 `Snake 1`、`Snake 2`…）。
**昵称在场上唯一**，登录框会即时提示已被占用的名字。奖杯按 `IP + 昵称` 记录，
**同一个 IP 开多个网页、用不同昵称，就是多个各自独立的玩家**，可以同时游玩、各记各的奖杯。

想让局域网外的朋友也能进来，见 [`docs/networking.md`](docs/networking.md)。

## 玩法

| 操作 | 作用 |
|---|---|
| `W` `A` `S` `D` | 移动（世界方向，非相对朝向） |
| `Shift` | 加速 —— 但**转向会明显变钝**，冲刺要付出代价 |
| `空格` | 跳跃 —— 滞空时**不吃道具**、可从别人身上跨过去 |
| 滚轮 | 拉近/拉远相机 |
| `M` | 静音 |

**规则**

- 地图是正方形，四边穿越到对侧；边界用一道发光的墙标出来，穿过去就到对侧。
- 吃到彩色道具，头部**增加**一颗同色珠。
- 身上出现 **3 颗及以上相连同色**即消除，可连锁；被消掉的珠子会先原地闪几下再消失。
- **长度归零 = 获胜**，奖杯 +1，弹出结算面板停顿 3 秒，然后换个位置重新开局。
- **彩虹万能珠**：每隔一段时间在随机位置成簇刷新（小地图上有标记），**可当作任意颜色**参与三消。
- **头撞别人身体**：对方从撞击点断尾，断尾接到你头前，对方的尾端变成你的新头（你会顺着他的旧路径倒着开出去）。接到断尾时会提示从谁身上接了多少颗。
- **头撞头**：比谁撞得更"正"（朝向与指向对方的夹角更小）。胜者头部直接消掉一颗珠，败者死亡；**正得一样则同归于尽**。
- **撞到自己**：死亡。蛇身长度超过最小转弯圆的周长时才可能咬到自己——短蛇转圈是安全的，长蛇才需要小心。
- **死亡**：珠子随蛇一起消失（只留一圈炸开的特效），原地停顿 3 秒并弹出死亡面板，然后在**死亡点附近**重生；死亡点会用光柱标记，重生后再保留几秒，方便你判断刚才发生了什么。
- **出生保护**期间完全不参与碰撞判定——既撞不到别人，也不会被别人撞；头上有护罩，快结束时会闪烁。若保护到期时仍和别人重叠，会自动延长到脱离接触为止。
- 断线不重连，重进即重新开始（奖杯保留）。

进场前可选 8 种珠子皮肤：玻璃珠、哑光陶土、抛光金属、霓虹发光、糖果釉面、极光虹彩、深空星河、熔岩裂纹。

## 技术选型

| 部分 | 选择 | 理由 |
|---|---|---|
| 渲染 | **three.js**（WebGL） | 浏览器打开就能玩，不用装客户端；PBR 材质足够做出弹珠质感 |
| 皮肤花纹 | **程序化 GLSL** | 通过 `onBeforeCompile` 注入，不需要手绘贴图，也不必随包分发 |
| 服务器 | **Node.js** + express + ws | 与客户端同语言，规则代码可以直接共用一份 |
| 网络模型 | **服务器权威** + 客户端纯插值 | 位置只认服务器，不做预测/外推，多人下不会各看各的 |
| 传输 | **WebSocket / JSON** | 局域网带宽足够，可读性优先于压缩率 |
| 构建 | **无构建步骤** | 浏览器原生 ES Module + importmap，改完刷新即可，不引入打包器 |
| 配置 | **单文件共享** | 服务端与客户端用同一份 `config/game.config.js`，客户端进场时随协议拿到 |
| 存档 | **JSON 文件** | 只存昵称与奖杯，每次变更即原子落盘，不值得引入数据库 |
| 测试 | **Node 自带 + 无头回归** | 规则、模拟、插值三组脚本，不引入测试框架 |
